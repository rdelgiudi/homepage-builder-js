# Pages

This site has more than one page. The homepage is the [showcase](/), with every widget type; this page and the [projects page](/projects) are linked from it with a **Links** widget.

Links inside markdown files count too: the [colophon](/colophon) is only linked from this file, and the editor still knows visitors can reach it (homepage → about → colophon).

## Same site, different settings

Every page follows the site's settings unless it has its own. Each group (name and tagline, title colors, layout, counters, background, effects) is either the site's or the page's own:

| Page | Its own settings |
| --- | --- |
| [Homepage](/) | none: the site-wide settings |
| About (this page) | none: looks exactly like the homepage |
| [Projects](/projects) | name and tagline, title colors, Bento layout, effects (widget frames, mouse trail), counters |
| [Colophon](/colophon) | background (animated gradient, aurora), Link in bio layout, title colors, counters |

In the admin panel, the *Header & layout*, *Background* and *Effects* screens switch between **Whole site** and **One page**. Only the favicon is the same on every page.
